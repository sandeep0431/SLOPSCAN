# Privacy

## Local-First Analysis

By default, SlopScan performs analysis inside the user's browser.

The extension reads webpage information only for the purpose of the current audit.

---

# Default Behavior

SlopScan does not require:

- A backend
- A user account
- An API key
- Uploading webpage content

---

# Optional Future AI Features

If an AI analysis feature is added:

The user must clearly know:

- What data is being sent
- Where it is being sent
- Which AI provider receives it

The feature must be opt-in.

---

# Principle

Never silently send:

- Website source
- Website text
- Screenshots
- User content

to an external service.
