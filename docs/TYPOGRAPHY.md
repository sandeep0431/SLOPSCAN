# Typography Audit

## Goal

Audit the existing typography system before recommending replacement fonts.

---

# Step 1 — Preserve Brand Identity

If a website uses a clear intentional brand typeface:

Do not automatically recommend replacing it.

First recommendation:

> Simplify the existing typography system.

---

# Step 2 — Detect Problems

Analyze:

- Font families
- Font sizes
- Font weights
- Letter spacing
- Line heights

---

# Step 3 — Product Direction

Infer broad categories using:

- Title
- Headings
- Meta description
- Visible keywords

Possible categories:

- Developer
- SaaS
- Finance
- Analytics
- Creative
- Editorial
- Commerce

---

# Example Suggestions

## Developer

Primary:

- IBM Plex Sans
- Space Grotesk

Technical metadata:

- IBM Plex Mono
- JetBrains Mono

---

## Modern SaaS

Primary:

- Manrope
- DM Sans

Body:

- Inter

---

## Editorial

Display:

- Playfair Display

Body:

- Source Serif 4

---

# Output

Always provide:

1. Keep current font
2. Simplify current system
3. Suggested direction
4. Alternative direction

Never present one font recommendation as the only correct answer.
